# FastAPI CRUD

CRUD simples desenvolvido para estudo de FastAPI e SQLAlchemy.

## Tecnologias

- FastAPI
- SQLAlchemy
- SQLite
- Pydantic

## Funcionalidades

- Criar usuário
- Listar usuários
- Buscar usuário por ID
- Atualizar usuário
- Remover usuário

## Executando

```bash
pip install -r requirements.txt
uvicorn main:app
```

## Acesse

```bash
http://127.0.0.1:8000/docs
```
